# Day 1: Git and GitHub Setup

## Task Description

Successfully configured Git on the local system by setting up global user credentials, creating a GitHub repository, cloning the repository to the local machine, and verifying the repository status using Git commands.

## Key Learnings

- Understanding the purpose of Git and version control systems.
- Configuring Git identity using global settings.
- Working with GitHub repositories and remote URLs.
- Cloning repositories from GitHub to a local machine.
- Using essential Git commands such as `git config`, `git clone`, and `git status`,`git push`,'git pull`.
- Understanding repository structure, folders, and README documentation.

## Outcome

Day 1 objectives were completed successfully. Git was configured correctly, the repository was cloned and accessed locally, and the fundamental concepts of Git, GitHub, and repository management were understood and practiced.
